📦 API Gestion des Retours Produits

✅ API est opérationnelle - Version 1.0.0

📋 Endpoints disponibles:

GET /retours

Retourne la liste de tous les retours

GET /retours/{id}

Retourne les détails d'un retour spécifique

POST /retours/create

Crée un nouveau retour

DELETE /retours/{id}

Supprime un retour

📝 Exemple de requête POST:

{
    "produit": "iPhone 13 Pro Max",
    "client": "Marie Lambert",
    "raison": "Produit défectueux",
    "etatTraitement": "EN_ATTENTE",
    "date": "2026-03-17"
}

🔗 Pour tester l'API, utilisez Postman ou votre navigateur
